# Measles Outbreak Prediction Using Machine Learning

## Project Overview
This project analyzes the influence of vaccination
coverage on measles outbreaks using machine learning.

## Objectives
1. Predict measles outbreaks using machine learning.
2. Evaluate and compare different classification models.
3. Analyze the influence of vaccination coverage.

## Technologies Used
- Jupyter Notebook
-  Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- joblib

## Machine Learning Models
1. Random Forest
2. Support Vector Machine (SVM)
3. XGBoost

## Results
XGBoost achieved the best performance with:
- Accuracy: 81%
- F1 Score: 65%
