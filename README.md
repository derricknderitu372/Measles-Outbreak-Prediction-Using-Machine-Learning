# Measles Outbreak Prediction Using Machine Learning

## Project Overview
This project analyzes the influence of vaccination coverage on measles outbreak occurrence using machine learning techniques. It involves data preprocessing, exploratory data analysis, model development, and evaluation to identify patterns associated with measles outbreaks.

## Objectives
1. Predict measles outbreaks using machine learning techniques.
2. Evaluate and compare the performance of different classification models.
3. Analyze the influence of vaccination coverage on measles outbreak occurrence.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost
- Joblib

## Machine Learning Models
Three classification algorithms were implemented and tuned to improve their predictive performance:

1. Random Forest
2. Support Vector Machine (SVM)
3. XGBoost

## Results and Key Findings

### 1. Measles Outbreak Prediction
Machine learning models were developed to predict measles outbreak occurrence based on vaccination coverage and other relevant factors.

### 2. Model Performance Comparison
The three classification models were evaluated using accuracy and F1 score after hyperparameter tuning.

| Machine Learning Model | Accuracy | F1 Score |
|------------------------|----------|----------|
| Random Forest (Tuned) | 80% | 64% |
| Support Vector Machine (Tuned) | 78% | 62% |
| **XGBoost (Tuned)** | **81%** | **65%** |

**Key Finding:** XGBoost achieved the best overall performance, with an accuracy of 81% and an F1 score of 65%, making it the preferred model for measles outbreak prediction.

### 3. Influence of Vaccination Coverage on Measles Outbreaks
The exploratory data analysis suggested an inverse relationship between vaccination coverage and measles outbreak occurrence.

**Key Findings:**
- Regions with vaccination coverage above 80% tended to experience fewer measles outbreaks compared to regions with lower vaccination coverage.
- Higher vaccination coverage was associated with a reduced likelihood of measles outbreak occurrence.
- The findings highlight the importance of strengthening vaccination programs to reduce measles outbreaks.

The 80% vaccination coverage threshold was used as a reference point in the exploratory analysis and should not be interpreted as a guaranteed threshold for preventing measles outbreaks.

## Conclusion
The study demonstrated the potential of machine learning techniques in predicting measles outbreaks and analyzing the influence of vaccination coverage.

Among the three classification models, **XGBoost (Tuned) achieved the best performance**, with an accuracy of **81%** and an F1 score of **65%**.

Furthermore, the analysis suggested that vaccination coverage above 80% was associated with reduced measles outbreak occurrence, emphasizing the importance of vaccination in measles prevention and control.
